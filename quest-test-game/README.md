# Quest Test Game

Standalone Meta Quest test game prototype.

Features:
- Y opens/closes the menu.
- Platforms
- Flying
- Super Jump
- Long Arms
- No giant/base plate.

## Quest-only GitHub build route

You do not need Android Studio to compile this project. GitHub Actions performs the build in the cloud.

1. Open the repository in the Quest browser.
2. Open **Actions**.
3. Select **Build Quest Test APK**.
4. Choose **Run workflow**.
5. Wait for the workflow to finish.
6. Open the completed workflow and download its APK artifact.
7. Install the APK on the Quest using your Quest-side installation method.

This project is a standalone test app and does not modify Gorilla Tag.
